# Ubuntu Bakery - WEDE5020 Part 1

## Project overview
Ubuntu Bakery is a fictional small bakery established in 2021 in Limpopo, South Africa. This website project provides information about the bakery, products, enquiries and contact details.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git/GitHub for version control

## Required pages
1. Home
2. About Us
3. Products
4. Enquiry
5. Contact

## Folder structure
- HTML files are in the project root.
- `css/style.css` contains presentation and responsive layout.
- `js/script.js` contains basic form validation.
- `assets/` contains original SVG illustrations created for this academic project.
- `SITEMAP.md` documents the navigation structure.

## Testing
Test all five pages in more than one browser and at desktop/mobile widths. Confirm:
- all navigation links work;
- images have alternative text;
- the enquiry form validates required fields;
- CSS loads correctly;
- JavaScript loads correctly;
- pages remain readable on small screens.

## GitHub
Create the private repository supplied by the lecturer and push this project. Use descriptive commit messages such as:
- Initial website structure
- Add HTML pages and navigation
- Add bakery content and assets
- Add responsive CSS
- Add enquiry form validation
- Update README and documentation
